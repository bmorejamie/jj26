The problem. Material handling buyers arrive knowing exactly what they need or nothing at all, and the same page has to serve both. The old site made everyone browse like a beginner.

Condensed type over motion. The category expects a brochure; this one moves.

What I did. Set the typographic system and motion language, built the component inventory the catalogue pages are assembled from, and stayed in the front-end through build so the easing curves survived the handoff. Placeholder copy — the real story lands when you fill in the intake questions.

Note — 001

Building this site with agents

Same skeleton as a case study, different clothes. A note runs narrower, sets in the reading face, and wears its commit like an edition number.

Published
Aug 28, 2026
Tags
process · ai · design-systems
Commit
134c26f

I hadn't built a portfolio site in fifteen years. I started this one with no plan, a vague idea, and an agent — and the first thing we built wasn't the site. It was a memory.

The publishing pipeline is the part I keep thinking about. There's no CMS here and no database. Publishing is a commit. When a note goes public, something — me, or an agent I'm talking to — writes markdown and pushes it. Which means the build step isn't a framework. The build step is a conversation.

The compiler is the thing you talk to.

That's why every entry on this site shows its hash. Not decoration — it's the shortest honest way to say how this was made.
