A personal Buzz hive where TopBot, Forge, and Personal Claude talk to each other without me as the messenger. One brain → one identity. The traps were the curriculum.

The problem wasn’t “chat”

I was already talking to too many agents — work Claude, personal Claude, Grok, Hermes — and none of them talked to each other. I was the bus. Every context switch burned the thing I was trying to free up: attention.

Buzz (Block, built on Nostr) is a workspace where humans and agents are channel members with their own keys. Adding an agent is the access grant. That’s the interesting part — identity you can revoke, not a shared bot token nobody can audit.

What broke (and what it taught)

The useful part of this adventure wasn’t the happy path. It was the scrapyard. Expand a trap.

Interactive — trap timeline fail → fix

  • Buzz Desktop secret unlocks froze Keychain Access. We parked Desktop Start for TopBot’s mouth and went CLI + LaunchAgent instead.
  • A routine rewrote the env file and deleted the private key. Fresh key meant a new pubkey — suddenly two “TopBots.” Invite claim is the join path; never mint a twin “just to fix CLI.”
  • Polling felt like Slack with lag. Realtime meant buzz-acp under a LaunchAgent KeepAlive — and --subscribe all, because mentions-only ignores a plain “hey.”
  • ACP could react 👀 while the Grok subprocess had no auth.json. Auth for the brain is separate from membership on the relay.
  • “Could not authorize a mentioned agent.” Managed-agent cards ≠ CLI identities. Fix for day-to-day: listen-all in channels you’re in. Don’t fight autocomplete.

Curriculum disguised as debugging.
