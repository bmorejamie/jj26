Building this site with agents

There's no CMS here, no database and no build step. Publishing a page and committing a file are the same action. Below is this site's actual history, pulled live.

Draft — this is scaffolding for the template, not finished writing. The artifact below is real and working.

The publishing pipeline is git

Every page on this site is a file in a public repository. To publish something, a file gets written and committed. That's the whole mechanism. It means the same action works whether a person does it or an agent does it on their behalf — there's no admin panel standing in between, and nothing to keep running.
